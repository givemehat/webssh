# Security policy

## Supported versions

Only the latest version on the default branch is supported.

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/givemehat/webssh/security/advisories/new)
instead of opening a public issue.

Run this service behind TLS and an authenticated reverse proxy in production.
Do not expose it directly to the public internet with default settings.
